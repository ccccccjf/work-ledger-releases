### 本次更新内容

- 会议正文自动补齐：打开会议详情就自动拉取智能纪要、时间轴、逐字稿，不用再点按钮
  （自动同步只存目录，正文按需拉，所以首次打开会转十几秒）
- 智能纪要按腾讯会议的结构重排：主题、发言人、摘要各自成行，章节「一、二、」带标线，
  小节「1. 2.」分层，条目「核心定位：…」标签加粗；不再是糊成一大段的纯文本
- 新增「时间轴」：腾讯会议按时段自动分段的 8 个节点，竖向时间线展示
- 纪要里的智能待办单独列出，可直接转成本地工作项
- 逐字稿：204 段按「时间 + 说话人 + 内容」排版，标题显示段数与拉取时间
- 录屏进工作台：云端录制可在应用内播放（内置浏览器，登录一次后续免登录）；
  本地录屏可关联 mp4/mov，用原生播放器打开，书签记住路径，下次直接播
- 会议目录同步时顺手刷新云录制信息（播放链接带临时 token，会变）

## 安装

1. 下载上面的 `Workbench-0.1.19.dmg`
2. 打开 dmg，把「个人工作台」拖进「应用程序」
3. 首次打开若提示「无法验证开发者」：右键点应用 → 打开（应用未做 Apple 公证）

## 更新

已装旧版本的不用重新下载：

- 应用内：设置 → 版本与更新 → 检查更新
- 或点左下角的更新按钮

应用会依次尝试 Gitee 与 GitHub 两个源，哪个先通就用哪个下载并校验安装。
