## 安装

1. 下载上面的 `Workbench-0.1.18.dmg`
2. 打开 dmg，把「个人工作台」拖进「应用程序」
3. 首次打开若提示「无法验证开发者」：右键点应用 → 打开（应用未做 Apple 公证）

## 更新

已装旧版本的不用重新下载：

- 应用内：设置 → 版本与更新 → 检查更新
- 或点左下角的更新按钮

应用会依次尝试 Gitee 与 GitHub 两个源，哪个先通就用哪个下载并校验安装。
